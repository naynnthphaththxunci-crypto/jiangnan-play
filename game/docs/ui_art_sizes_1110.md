# 江南合成 · 合成界面美术尺寸

## 整屏
- 设计尺寸：1080×1920（9:16）
- 背景实际画：1080×2340。按钮、棋盘、订单这些重要内容只放在中间 1080×1920 的范围里，上下多出来的 210 像素只画背景，这样长屏手机不会露黑边。
- 可以先画一张整屏效果图（带全部部件）看整体，再把每个部件单独出图。

## 部件尺寸（都按 1080 宽的比例，透明底 PNG）

| 部件 | 尺寸（像素） | 说明 |
|---|---|---|
| 整屏背景 | 1080×2340 | 只画背景，不带按钮和格子 |
| 棋盘底板 | 1000×1290 | 7 列 × 9 行整块底板（木板或布面） |
| 单个格子 | 144×144 | 做三种：空格、半遮掩、封闭 |
| 棋子 | 256×256 | 按《子棋美术需求_1110》，游戏里会缩小显示 |
| 订单客人头像 | 512×512 | 只露头和肩，和现在一样 |
| 订单托盘 | 320×120 | 压在客人身前的木托盘 |
| 顶栏 | 1080×180 | 放体力、金币、钻石、等级 |
| 顶栏小图标 | 96×96 | 体力、金币、钻石、经验各一个 |
| 底部详情栏 | 1000×200 | 点棋子后显示名字和信息的那一条 |
| 圆形按钮 | 160×160 | 商城、建造、设置等 |
| 长条按钮 | 400×140 | 领取、确定等 |
| 弹窗底板 | 900×1100 | 礼包、升级等弹窗 |

## 出图要求
- 格式：PNG，背景透明（整屏背景除外），sRGB。
- 主体居中，四周留一点空，不要贴边。
- 不要把文字、数字画进图里，文字由程序加，改字不用重画。
- 风格和棋子一致：简单、中式、暖色、细深棕描边。

## 命名
小写英文加下划线，不要中文和空格：
- 背景 `ui_bg.png`，棋盘底板 `ui_board.png`
- 格子 `cell_empty.png`、`cell_half.png`、`cell_locked.png`
- 托盘 `ui_tray.png`，顶栏 `ui_topbar.png`，详情栏 `ui_infobar.png`
- 图标 `icon_energy.png`、`icon_coin.png`、`icon_gem.png`、`icon_exp.png`
- 圆形按钮 `btn_shop.png`、`btn_build.png`、`btn_setting.png`（其他按钮照此 `btn_英文名.png`）
- 长条按钮 `btn_long.png`，弹窗底板 `ui_popup.png`

整理好后放进 `jiangnan_ui_v1` 文件夹，压成 zip 发我。
